# Fixture data (synthetic)

These JSON files are **throwaway** stand-ins for DP-Contactor and WiNbreak2
catalogue content. Product IDs, ratings, and brochure text are invented so the
agent graph can run before the production schema lands.

Expect a major rewrite when real catalogue data arrives. Keep product facts out
of Python modules — only edit files in this directory (and the fixtures backend
loader if the JSON shape changes).
